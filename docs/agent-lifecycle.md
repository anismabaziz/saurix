# The Lifecycle of an AI Agent using Saurix

Generated by `scripts/generate_mcp_demo.py` from a real run of the MCP server. The story is the same every time; the numbers, symbol ids and file paths are whatever that repository actually produced.

<!-- provenance -->

The task: an agent is dropped into a repository it has never seen and has to work out where indexing is wired in, before it changes anything.

## With and without Saurix

| Question | Without Saurix | With Saurix |
| :--- | :--- | :--- |
| What is in here? | Read files until the shape appears | `stats`, 1104 nodes in one call |
| Where is it defined? | Grep, then read the hits | `find_symbol`, definition at `saurix/core/indexing.py` |
| What touches it? | Trace imports by hand | `callers`, 3 call sites; `impact_of_symbol`, 8 symbols within three hops |
| How are they connected? | Follow call sites in the editor | `path_between`, `cmd_index` -> `core.indexing.build_graph` |
