# MCP Demo (Saurix)

Generated by `scripts/generate_mcp_demo.py`. Every call below was executed against a real repository and every response is the real response, minus the `duration_ms` fields, which change on every run.

<!-- provenance -->
- Indexed repository: `anismabaziz/saurix` (source `.`)
- Indexed commit: `6ab8b4b948e3a0b6b98b3b3de837aeea48320991`
<!-- /provenance -->

Refresh it with:

```sh
uv run scripts/generate_mcp_demo.py
```

## Prerequisites

- Run `uv sync`.
- Start the server with `saurix-mcp`, then send the calls below.
- `source` is `.` here because the run was made against a local checkout. The tool takes a GitHub URL just as happily.

## 6. Find the path between two symbols

Tool call:

```json
{
  "tool": "path_between",
  "arguments": {
    "graph": "tmp/saurix.demo.graph.json",
    "source": "python://saurix.cli.commands:cmd_index",
    "target": "python://core.indexing.build_graph",
    "max_depth": 12
  }
}
```

Response:

```json
{
  "ok": true,
  "data": [
    {
      "step": "0",
      "edge": "",
      "id": "python://saurix.cli.commands:cmd_index",
      "type": "function",
      "name": "cmd_index",
      "file": "saurix/cli/commands.py"
    },
    {
      "step": "1",
      "edge": "CALLS",
      "id": "python://core.indexing.build_graph",
      "type": "symbol",
      "name": "core.indexing.build_graph",
      "file": ""
    }
  ],
  "meta": {
    "count": 2
  }
}
```

The shortest directed walk joining them, one row per step.
